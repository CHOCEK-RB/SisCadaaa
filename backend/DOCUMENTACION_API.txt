# Rutas de la API SisCadaaa

## Autenticación

### POST /auth/google/login
**Descripción:** Autenticación con Google OAuth
- **Requiere:** Token de Google en el cuerpo
- **Cuerpo:** `{ "token": "string" }`
- **Retorna:** 
  - Status 200: `{ "success": true }`
  - Establece cookie `auth_token` con el JWT
- **Errores posibles:** 401 (Unauthorized), 403 (Forbidden)
- **Autenticación:** No requiere autenticación previa

### POST /auth/logout
**Descripción:** Cierra la sesión del usuario
- **Requiere:** Cookie `auth_token`
- **Retorna:** 
  - Status 200: `{ "success": true, "message": "Logged out successfully" }`
- **Errores posibles:** 401 (Unauthorized)
- **Autenticación:** Requiere autenticación (cookie)

## Usuarios

### GET /user/profile
**Descripción:** Obtiene el perfil del usuario autenticado
- **Requiere:** Cookie `auth_token` o header Authorization
- **Retorna:** 
  - Status 200: Objeto con la información del perfil del usuario
- **Errores posibles:** 401 (Unauthorized)
- **Autenticación:** JWT (cookie o header)

### POST /user/pre-register
**Descripción:** Pre-registra un nuevo usuario
- **Requiere:** Datos de pre-registro en el cuerpo
- **Cuerpo:** DTO de pre-registro
- **Retorna:** 
  - Status 201: Resultado del pre-registro
- **Errores posibles:** 400 (Bad Request), 409 (Conflict)
- **Autenticación:** No requiere autenticación previa

### PATCH /user/:id/activate
**Descripción:** Activa un usuario previamente registrado
- **Parámetros:** `id` (string) - ID del usuario a activar
- **Retorna:** 
  - Status 200: Resultado de la activación
- **Errores posibles:** 400 (Bad Request), 404 (Not Found)
- **Autenticación:** No requiere autenticación previa

## Asistencia

### GET /attendance/my-attendance/:academicCourseId
**Descripción:** Obtiene la asistencia del estudiante para un curso académico específico
- **Parámetros:** `academicCourseId` (UUID) - ID del curso académico
- **Requiere:** Cookie `auth_token` o header Authorization
- **Retorna:** 
  - Status 200: DTO de asistencia del estudiante para el curso
- **Errores posibles:** 401 (Unauthorized), 403 (Forbidden), 404 (Not Found)
- **Autenticación:** JWT (cookie o header)

### GET /attendance/group/:groupId/history
**Descripción:** Obtiene el historial de asistencia de un grupo
- **Parámetros:** `groupId` (UUID) - ID del grupo académico
- **Requiere:** Cookie `auth_token` o header Authorization
- **Retorna:** 
  - Status 200: Arreglo con el historial de asistencias
- **Errores posibles:** 401 (Unauthorized), 403 (Forbidden), 404 (Not Found)
- **Autenticación:** JWT (cookie o header)

### POST /attendance/group/:groupId/take
**Descripción:** Toma asistencia para un grupo
- **Parámetros:** `groupId` (UUID) - ID del grupo académico
- **Requiere:** Cookie `auth_token` o header Authorization
- **Cuerpo:** DTO con estados de asistencia de estudiantes
- **Retorna:** 
  - Status 200 o 201 dependiendo de la operación
- **Errores posibles:** 401 (Unauthorized), 403 (Forbidden), 404 (Not Found)
- **Autenticación:** JWT (cookie o header)

### GET /attendance/group/:groupId/check
**Descripción:** Verifica si se puede tomar asistencia para un grupo
- **Parámetros:** `groupId` (UUID) - ID del grupo académico
- **Requiere:** Cookie `auth_token` o header Authorization
- **Retorna:** 
  - Status 200: DTO con información sobre si se puede tomar asistencia
- **Errores posibles:** 401 (Unauthorized), 403 (Forbidden), 404 (Not Found)
- **Autenticación:** JWT (cookie o header)
